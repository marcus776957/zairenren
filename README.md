# 再忍忍 💰

> 哄自己上班防止裸辞的网站

**👉 在线使用：[https://www.zairenren.fun](https://www.zairenren.fun)**

一款实时计算打工收入的趣味工具。在经济下行、就业形势严峻的当下，看着钱一秒一秒地往上涨，辞职的念头也就淡了。

**作者：** Marcus | **小红书：** https://xhslink.com/m/Ah9gwxzdnP3

## 功能

| 功能            | 说明                                              |
| --------------- | ------------------------------------------------- |
| ⏱ 实时计薪      | 每秒刷新收入金额，精确到分                        |
| 🏦 存钱罐       | 金币堆叠动画，越赚越满                            |
| 🎯 梦想提货清单 | 自定义目标，实时进度 + "还需忍耐"倒计时           |
| 📊 收入统计     | 今日/本周/本月汇总 + 7天趋势图                    |
| 📋 工作记录     | 自动保存每次上班的时长和收入                      |
| 💭 励志语录     | 30条扎心语录，点击换一句                          |
| 🏆 成就系统     | 8枚徽章（百元/早起鸟/周末战士/加班侠/连续打卡等） |
| 💰 扣税模式     | 可选开启，输入税率显示税后收入                    |
| 💾 本地存储     | 所有数据存在浏览器，关闭不丢失                    |

## 收入计算

```
每秒收入 = 月薪 ÷ (每月天数 × 每日工时 × 3600)
```

月薪 10000 元，22 天，8 小时/天：每秒 ≈ ¥0.0158

## 快速开始

```bash
npm install
npm run dev    # 开发预览
npm run build  # 构建产物
```

## 技术栈

- uni-app (Vue 3 + Vite + Pinia)
- 纯前端，localStorage 存储
- ESLint + Prettier + husky + commitlint
